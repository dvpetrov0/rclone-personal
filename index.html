Personal access to Google Drive on Ubuntu

rclone-personal is a desktop configuration of the open-source rclone tool, maintained by dvpetrov0 for personal use.

Its purpose is to make an authorized Google Drive account accessible through a mounted folder on the owner's Ubuntu computer. Files can be opened in desktop applications and managed through the file manager.

What the connection does

  • Lists files and folders and reads their metadata and contents.
  • Creates, uploads, updates, renames, moves, or deletes files when the owner or a desktop application performs those operations in the mounted folder.
  • Retrieves file contents as needed and uses a local cache according to the desktop configuration.

Authorization and data handling

The owner grants access through Google's OAuth authorization screen. The desktop client communicates with the Google Drive API; this informational website does not handle the sign-in process or receive Drive files or authorization tokens.

The requested drive permission enables access to existing files and supports both reading and writing. The privacy policy explains how this personal configuration handles the data.

Owner and contact

This personal configuration is maintained by the owner of the dvpetrov0/rclone-personal repository. Questions about the configuration or this policy can be submitted through the repository's Issues page.
