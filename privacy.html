Privacy policy

Effective date: 17 November 2026

This policy describes rclone-personal, a personal desktop configuration of rclone maintained by dvpetrov0.

Google data accessed and its purpose

After the owner authorizes a Google account, the desktop client can access Drive file and folder metadata and file contents. It uses this access to display a mounted folder and carry out file operations requested by the owner or applications accessing that folder. Operations may include reading, downloading, creating, uploading, updating, renaming, moving, and deleting files.

Google handles account sign-in. The desktop client stores OAuth credentials and authorization tokens to maintain the connection; it does not collect the owner's Google password.

Storage, transfers, and sharing

The desktop client exchanges data with Google's services over HTTPS. Its configuration, tokens, and any file cache are stored locally on the owner's computer. Files opened through the mounted folder are also accessible to the desktop applications chosen by the owner.

This personal configuration does not operate a separate server for receiving Drive files. Its operator does not sell Google user data or use it for advertising, profiling, or training AI models. This informational GitHub Pages website receives no Drive files or OAuth credentials.

Retention and removal

Local cache retention follows the rclone settings. The owner can remove cached files after pending uploads have completed and remove saved credentials when disconnecting the configuration. Google Drive files remain subject to the owner's actions in Drive or the mounted folder.

Access can be revoked through Google Account connections. Revocation prevents continued authorized access; it does not itself erase files already cached on the computer.

Google API data use

Information received through Google APIs is used only to provide this personal file-access function, in accordance with the Google API Services User Data Policy and its Limited Use requirements.

This website

These static pages contain no sign-in form, analytics scripts, or advertising. GitHub provides the hosting and may process technical request information, such as IP addresses, under the GitHub Privacy Statement.

Contact and updates

The configuration's owner can be contacted through the repository's Issues page. Any changes to these data practices will be reflected in this policy and its effective date.
